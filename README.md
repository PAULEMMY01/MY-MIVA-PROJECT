# Student Portfolio and Academic Management Website

A responsive, five-page HTML/CSS/JavaScript university assignment.

## Run locally
Open `index.html` in a modern browser. For testing, you may also use VS Code Live Server.

## Features
- Semantic HTML, tables, lists, images, hyperlinks, form and HTML5 video element
- Responsive CSS Grid/Flexbox, transitions and mobile navigation
- Academic planner: add, complete, delete and save tasks using localStorage
- Contact form: required fields, email pattern and digits-only phone validation

## Customize before submission
1. Replace `assets/profile.svg` with your photograph and update the image path in `index.html`.
2. Add `assets/introduction.mp4` or update the video source in `about.html`.
3. Replace project illustration placeholders and demo links with real screenshots and project URLs where possible.
4. Review all personal details and course information.
5. This contact form is client-side only: it validates but does not send messages. Connect a backend/form service if actual delivery is required.

## Publish
Create a public GitHub repository, upload all files preserving folders, then enable GitHub Pages in Settings → Pages → Deploy from branch → main / root. The live site will normally be at `https://USERNAME.github.io/REPOSITORY/` after deployment. Submit that live URL and the repository URL.
